- 内部平台（海外仓、OA 审批等）的网页可以在这个浏览器里直接操作：`navigate_page`、`new_page` 打开，`click`、`fill`、`press_key` 操作，
  `take_snapshot` 读内容，`evaluate_script` 取页面数据，`list_network_requests` 查接口返回。查询、筛选、翻页、展开详情、导出查看都可以直接做。
- 默认后台操作，不打扰负责人：`new_page` 传 background: true，`select_page` 传 bringToFront: false。
- 卖货店铺后台、广告后台不能在浏览器里打开或操作（会被拦截），它们只走官方 API 和提案。
- 对外生效或不可撤回的动作 —— 提交单据、审批通过或驳回、删除、改价、发消息 —— 把表填好、停在最后一步，用 ask_owner 说清要点什么、
  有什么后果、能不能撤回，等负责人回复后再点；能写成 browser.flow 提案的照常提案。
- 登录按下方「本轮自动登录权限」执行：已授权域名可使用负责人提供的凭证登录；其他域名请负责人登录。
- 任务结束、截图存好后，关掉本任务打开的标签页，原来就开着的留着不动。
- 每次跳转、点击、填写都会写审计，负责人事后能查。
