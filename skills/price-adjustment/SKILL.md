# 商品价格调整 SOP

## 适用场景

- 应对竞争对手降价
- 清理库存促销
- 大促活动准备
- 成本变动调整

## 操作步骤

### 1. 确认调价范围和幅度

- 获取当前价格和目标价格
- 计算调整幅度（不超过30%）
- 确认是否需要审批

### 2. 检查硬上限

使用 `get_shop_context(shop_key)` 查询：
- 单日调价次数上限
- 单次调价幅度上限
- 是否在白名单内

### 3. 提交调价提案

使用 `propose_action` 提交：
```json
{
  "type": "price.adjust",
  "shop": "店铺标识",
  "sku": "商品SKU",
  "current_price": 99.99,
  "target_price": 79.99,
  "reason": "竞品降价，跟进调整",
  "urgency": "normal"
}
```

### 4. 等待审批

- 金额变动 > 1000元：需要财务审批
- 降价幅度 > 20%：需要运营总监审批
- 其他：运营主管审批

## 注意事项

- ⚠️ 大促期间（618、双11）调价需提前3天
- ⚠️ 不要在流量高峰期（10-22点）频繁调价
- ⚠️ 调价后观察30分钟再考虑二次调整
- ✅ 记录调价原因和预期效果
