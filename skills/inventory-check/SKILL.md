# 库存异常排查 SOP

## 适用场景

- 后台显示有货但下单失败
- 库存数字突然归零
- 多个订单显示"库存不足"
- 库存数字异常增长

## 排查步骤

### 1. 确认问题范围

- 影响的 SKU 数量
- 影响的店铺/仓库
- 开始时间点
- 是否有系统报错

### 2. 检查数据一致性

使用 `feishu_search` 查找历史记录：
- 最近的库存同步日志
- 最近的订单扣减记录
- ERP 同步状态

### 3. 对比多个数据源

- 店铺后台显示库存
- ERP 系统库存
- 海外仓实际库存
- 在途库存

### 4. 常见原因

| 原因 | 表现 | 解决方案 |
|------|------|----------|
| 同步延迟 | 后台更新但 ERP 未同步 | 等待10分钟或手动触发同步 |
| 超卖保护 | 有货但不让下单 | 检查超卖阈值设置 |
| 锁定库存 | 数字正常但提示不足 | 查看是否有未支付订单锁定 |
| 系统故障 | 库存突然归零 | 联系技术支持恢复 |

### 5. 临时处理

如果确认是数据不一致：
1. 拍摄证据截图（使用 `capture_page` 工具）
2. 提交紧急修正提案
3. 通知相关负责人
4. 记录处理过程

## 升级路径

- 轻微不一致（< 10件）：运营主管处理
- 大量缺货（> 100单受影响）：升级运营总监
- 系统性故障：立即通知技术团队

## 预防措施

- 每天定时比对库存（早9点、晚6点）
- 大促前提前3天锁定安全库存
- 新品上架后24小时内重点关注
