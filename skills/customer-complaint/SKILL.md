# 客诉处理 SOP

## 适用场景

- 客户投诉产品质量问题
- 差评处理
- 退换货纠纷
- 物流延迟投诉

## 处理原则

1. **快速响应**：2小时内首次回复
2. **同理心**：先理解客户感受再解释
3. **方案导向**：提供具体解决方案，不空谈
4. **留证据**：所有沟通和处理步骤都截图存档

## 标准流程

### 1. 信息收集

从飞书消息或工单中提取：
- 订单号
- 商品 SKU
- 问题描述
- 客户诉求
- 紧急程度

### 2. 问题分类

| 类型 | 响应时限 | 处理权限 |
|------|---------|---------|
| 产品质量 | 2小时 | 可直接补发/退款（< 500元） |
| 物流延迟 | 4小时 | 协调物流商，提供补偿方案 |
| 服务态度 | 1小时 | 道歉 + 优惠券 |
| 恶意差评 | 12小时 | 评估申诉，必要时法务介入 |

### 3. 解决方案

**产品问题**：
1. 确认问题（要求客户提供照片）
2. 评估责任方（供应商/物流/操作失误）
3. 提供选项：退款/换货/补偿
4. 优先选择成本低、客户满意度高的方案

**物流问题**：
1. 查询物流轨迹
2. 联系物流商催促
3. 超时赔付（按平台规则）
4. 严重延迟：全额退款 + 补偿

**差评处理**：
1. 私信沟通了解原因
2. 提供补救方案
3. 请求修改评价（不强求）
4. 无法挽回：在评价下公开回复说明

### 4. 权限和审批

- 直接处理：< 500元补偿，标准退换货
- 需要审批：> 500元补偿，非标准处理，涉及供应商索赔
- 紧急情况：先处理再补报备

### 5. 记录和复盘

每个客诉处理后：
- 使用 `report_step` 记录处理过程
- 标记问题根因
- 是否需要改进 SOP
- 是否需要通知供应商/物流商

## 沟通话术模板

### 产品质量问题
```
非常抱歉给您带来不好的体验。我们已经确认了问题，为您提供以下解决方案：
1. 全额退款，无需退货
2. 重新发货新品，运费我们承担
请您选择更方便的方案，我们会立即处理。
```

### 物流延迟
```
您好，我们已经与物流公司确认，包裹目前在 [位置]，预计 [时间] 送达。
考虑到给您带来的不便，我们为您准备了 [补偿方案]。
如果超过预计时间仍未送达，我们将立即全额退款。
```

## 升级机制

- 客户情绪激动：立即升级主管介入
- 涉及法律纠纷：升级法务
- 媒体曝光风险：升级公关团队
- 平台介入：配合平台客服，及时提供证据

## 注意事项

- ⚠️ 不要承诺无法兑现的补偿
- ⚠️ 不要与客户争论对错
- ⚠️ 不要泄露其他客户信息
- ✅ 保持专业礼貌的语气
- ✅ 及时同步进展给客户
